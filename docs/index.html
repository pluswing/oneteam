Issue-first Loop Engineering that stays local

OneTeam works with a Git repository on your machine. Each imported project keeps its own `.oneteam` database, skills, and memory under the repository root, so switching projects swaps the whole AI development state with the code.

Issue

Write issues, not loop settings

Describe the work in an issue. Requirements agents infer the goal contract, evidence, risk policy, and handoff conditions.

Objective

Keep a standing objective

One objective run follows the issue and linked pull request across implementation, review, fixes, QA, and verifier judgment.

Agent Job

Gate completion with evidence

Hard verification gates require command results, changed files, stop reasons, and verifier evidence before the loop can stop safely.

Scheduler

Discover work in the background

The internal scheduler creates missing objectives for open issues and turns repository problems into triage items.

Judge

Separate builder and judge

Verifier jobs are recorded as judge decisions with their AI provider, missing evidence, notes, and ready-to-merge status.

Comments

Use richer agent reports

Agents can write Markdown or sanitized HTML comments, enabling compact tables, callouts, and structured status reports.

From Issue to Verified Pull Request

The user-facing flow stays simple: create an issue, answer questions if needed, then inspect the pull request. The loop control plane runs behind that workflow.

  1. 1. Register a repository Import a Git repository, choose Codex, Claude Code, or LM Studio, then let OneTeam create project-local `.oneteam` state.
  2. 2. Create an issue Describe the work. OneTeam creates a standing objective and uses requirements to define acceptance evidence.
  3. 3. Let agents run and judge Implementation, review, fix, QA, and verifier agents run in worktrees, collect evidence, and update objective state.
  4. 4. Merge with judgment When verifier marks the pull request ready to merge, inspect the objective summary and evidence, then merge yourself.

Download the App

OneTeam is distributed as a macOS app from GitHub Releases. Download the latest DMG, open OneTeam.app, then choose Codex, Claude Code, or LM Studio on first launch. No local build is needed.

  1. Download the latest release from GitHub Releases.
  2. Open the DMG and launch OneTeam.app.
  3. Select or add a repository so OneTeam stores its DB, skills, and memory under that repo.
  4. Create an issue and let OneTeam run the objective-backed AI development loop behind it.
